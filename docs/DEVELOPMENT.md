# Smart Frame

Фоторамка с управлением умным домом (Home Assistant). PWA + WebView-лаунчер для Android 5+.

- **Режим покоя** — фото на весь экран, часы, сводка по дому. Экран не гаснет.
- **Касание** — панель управления: климат, свет, камеры, датчики. Без касаний возвращается к фото.

- **Карточки настраиваются** прямо на рамке: карандаш в панели → сетка 12 колонок с квадратными клетками;
  карточку тянут пальцем (перенос) или за уголок (размер), остальные раздвигаются и поджимаются вверх.
  В редакторе карточки — цвет, иконка, устройства из списка HA, информер на фото.
  Типы: климат, свет/розетки, камеры, датчики, сценарии, кондиционер, колонки, телевизор, погода.
  В карточку можно добавить устройство целиком — оно раскроется в подходящие сущности.
- **Несколько домов**: у каждого своя раскладка и свой HA (или тот же). Переключение — боковым свайпом
  по панели; главный дом выбирается на каждом устройстве отдельно («Настройки → Дома»).
- **Подробности**: тап по датчику — график за 24 ч / 7 / 30 дней и статистика из истории HA.

## Сервис рамок

`server/` — мини-сервис для дома (Node 22, встроенный `node:sqlite`, Hono). Хранит в `data/frame.db`
настройки HA, раскладку карточек и общий альбом (файлы в `data/photos`), раздаёт PWA и рассылает изменения
всем рамкам через Server-Sent Events — правка на одной рамке сразу видна на остальных.

К Home Assistant рамки ходят **через сервис** (`/api/ha/websocket`, камеры — `/api/ha/camera/<entity>`):
токен хранится только в `data/frame.db`, через API он не отдаётся и в сборку PWA не попадает.

```bash
npm run build && npm run server   # http://<адрес>:8787 — открыть на рамках/планшетах
```

Порт — `SERVICE_PORT`, каталог данных — `DATA_DIR`. Если PWA открыт без сервиса (как статика),
рамка работает автономно: настройки в localStorage, фото в IndexedDB.

## Разработка

```bash
cp .env.example .env.local   # HA_URL / HA_TOKEN — начальные значения для пустой базы сервиса
npm install
npm run dev                  # Vite (http://localhost:5173) + сервис (8787), /api проксируется
```

Начальная раскладка — `src/config.ts` (используется, пока в сервисе пусто). Фото в сборку — `src/photos/`
(файлы `demo-*` — заглушки, не коммитятся).

## Сборка

```bash
npm run build        # dist/ — PWA, можно положить в HA: config/www/frame → http://ha:8123/local/frame/
npm run apk:debug    # android/app/build/outputs/apk/debug/app-debug.apk
npm run apk          # release (пока подписан debug-ключом)
```

В APK по умолчанию зашит собранный `dist/`; адрес сервиса тогда указывается в «Настройки → Сервис».
Либо задайте `START_URL` в `android/app/build.gradle` = адрес сервиса — рамка будет грузить PWA с него
и обновляться без пересборки.

## Совместимость с Android 5

Системный WebView на рамках бывает Chrome 37 без обновлений, поэтому:

- `@vitejs/plugin-legacy` собирает ES5-бандл; **Vite 7, не 8** — у Vite 8 (rolldown) полифиллы содержат стрелочные функции;
- минификация terser с `ecma: 5`;
- в CSS нет Grid, `gap`, CSS-переменных (разворачиваются postcss) и blur;
- проверка: `npx acorn --ecma5 dist/assets/*-legacy-*.js`.

## iOS

PWA: Safari → «Поделиться» → «На экран Домой». Экран держит Screen Wake Lock (iOS 16.4+), иначе — NoSleep.
