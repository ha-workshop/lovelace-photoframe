# Smart Frame

Фоторамка с управлением умным домом (Home Assistant): карточка дашборда HA (HACS), PWA и APK-оболочка
для старых Android-рамок.

- **Режим покоя** — фото на весь экран, часы, сводка по дому. Экран не гаснет.
- **Касание** — панель управления: климат, свет, камеры, датчики. Без касаний возвращается к фото.

- **Карточки настраиваются** прямо на рамке: карандаш в панели → сетка 12 колонок с квадратными клетками;
  карточку тянут пальцем (перенос) или за уголок (размер), остальные раздвигаются и поджимаются вверх.
  В редакторе карточки — цвет, иконка, устройства из списка HA, информер на фото.
  Типы: климат, свет/розетки, камеры, датчики, сценарии, кондиционер, колонки, телевизор, погода.
  В карточку можно добавить устройство целиком — оно раскроется в подходящие сущности.
- **Дома и экраны**: у каждого дома несколько экранов («Гостиная», «Камеры», «Климат») — свои сетки
  карточек; боковой свайп листает экраны, за последним — экраны следующего дома. Стартовый экран
  выбирается на каждом устройстве отдельно («Настройки → Дома»).
- **Подробности**: тап по датчику — график за 24 ч / 7 / 30 дней и статистика из истории HA.

## Где что хранится

Всё — в Home Assistant, токенов и своих серверов нет:

- дома, экраны и настройки слайдшоу — в конфиге карточки `custom:photoframe-card` на дашборде
  «Фоторамка» (`/photo-frame`); формат дома — `layouts.<дом> = { screens: [{ id, name, cols, cards }] }`
  (старая одна раскладка на дом читается как один экран);
- фото — в медиатеке HA, `/media/photoframe`.

**Карточка** работает внутри фронтенда HA через его объект `hass` — от имени вошедшего пользователя.

**PWA** входит в HA так же, как сам фронтенд HA (OAuth2, `lib/haAuth.ts`): на том же домене берёт
сессию HA этого браузера, внутри HA (дашборд «Веб-страница», приложение HA) — вход страницы вокруг,
иначе кнопка «Войти через Home Assistant» ведёт на страницу входа HA. Вход хранится только на устройстве.
Дальше PWA читает и пишет ту же карточку на дашборде «Фоторамка» и следит за `lovelace_updated` —
правка в карточке или на другой рамке видна сразу. Пока входа нет или дашборда нет — всё живёт в
браузере (localStorage + IndexedDB); при переходе на HA рамка предложит перенести это в HA.

## Разработка

```bash
npm install
npm run dev                  # Vite: http://localhost:5173 — PWA (вход через ваш HA: адрес в «Настройки → Home Assistant»)
npm run build:card           # dist/photoframe-card.js — файл, который ставит HACS
```

Стенд карточки: `card-harness.html?ha=http://<HA>:8123` — имитация дашборда с живыми данными вашего HA
(только чтение; сохранение конфига и медиатека — заглушки). `?hadom` — ещё и DOM фронтенда HA для киоска.

## Сборка и деплой

```bash
npm run build                # dist/ — PWA и карточка
./deploy.sh pwa              # PWA → <config>/www/photoframe → http://<HA>:8123/local/photoframe/index.html
./deploy.sh card             # карточка → <config>/www/community/lovelace-photoframe (как ставит HACS)
npm run apk                  # android/build/photoframe.apk — оболочка для рамок
npm run apk:install          # собрать и поставить на рамку по adb
```

Настройки деплоя — `.deploy.env` (пример: `deploy.env.example`).

APK (`android/`, без Gradle: aapt2 → javac → d8 → apksigner) — полноэкранный WebView. В нём задаётся только
адрес HA; страница — `<HA>/local/photoframe/index.html`, так что `./deploy.sh pwa` обновляет интерфейс без
переустановки. Экран держит сама оболочка (`FLAG_KEEP_SCREEN_ON`), отладка — `chrome://inspect`.

## Совместимость с Android 5

Системный WebView на рамках бывает Chrome 37 без обновлений, поэтому:

- `@vitejs/plugin-legacy` собирает ES5-бандл; **Vite 7, не 8** — у Vite 8 (rolldown) полифиллы содержат стрелочные функции;
- минификация terser с `ecma: 5`;
- в CSS нет Grid, `gap`, CSS-переменных (разворачиваются postcss) и blur;
- запросы — через XMLHttpRequest (fetch появился в Chrome 42);
- проверка: `npx acorn --ecma5 dist/assets/*-legacy-*.js`.

## iOS

PWA: Safari → «Поделиться» → «На экран Домой». Экран держит Screen Wake Lock (iOS 16.4+), иначе — NoSleep.
