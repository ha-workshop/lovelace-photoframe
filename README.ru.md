# Photo Frame — фоторамка для Home Assistant

[English](README.md) · **Русский**

**Ваш планшет или старый телефон превращается в фоторамку, которая заодно управляет домом.**
Днём и ночью на экране — ваши фото, часы и погода. Смахнули вверх — и под рукой свет, климат,
кондиционер, камеры, колонки и телевизор. Через минуту без касаний — снова фото.

> *A digital photo frame for Home Assistant: full-screen slideshow with clock and weather;
> swipe up for a customizable smart-home control panel. HACS dashboard card, no add-ons, no tokens.*

## Что умеет

- **Фоторамка.** Фото на весь экран с медленным приближением, большие часы, дата и погода из вашей
  интеграции погоды. Внизу — информеры: температура, сколько горит света, мощность, открытая дверь.
  Тап по информеру — карточка поверх фото, слайдшоу не прерывается.
- **Смахните вверх — панель дома.** Как экран блокировки iPhone: фон превращается в размытую копию
  текущего фото, цвет интерфейса подстраивается под снимок.
- **Карточки собираете сами.** Сетка 12 колонок с квадратными клетками: перетащите карточку пальцем,
  потяните уголок — размер. Типы карточек:
  климат · свет и розетки · камеры · датчики · сценарии · кондиционер · колонки · телевизор · погода.
  В карточку можно добавить **устройство целиком** — например, умный автомат раскроется в напряжение,
  ток, мощность и энергию.
- **Графики и статистика.** Тап по градуснику или датчику — история за 24 часа, 7 и 30 дней:
  минимум, максимум, среднее, расход по часам и дням, сколько раз и как долго был включён прибор.
- **Экраны и дома.** У каждого дома несколько экранов — «Гостиная», «Камеры», «Климат», у каждого своя сетка
  карточек; свайп вбок листает их (за последним экраном — экраны следующего дома). Дома собираются из устройств
  этого же Home Assistant (дачу можно подключить к нему, например, через Remote Home Assistant).
  На каждом устройстве свой стартовый экран, к которому рамка возвращается сама.
- **Экран не гаснет.** Вместо сна — фото (Screen Wake Lock на HTTPS).
- **Аккуратно с данными.** Недоступные датчики скрываются, выключение автомата — в два касания.
- **Русский и английский** интерфейс: язык берётся из профиля HA (или браузера), можно выбрать вручную.
  Другие языки добавляет сообщество — см. [CONTRIBUTING.md](CONTRIBUTING.md).

## Как это устроено

Photo Frame — это **одна карточка дашборда** (`custom:photoframe-card`), а не аддон и не интеграция.

- **Доступ к дому — от имени вошедшего пользователя.** Карточка работает внутри фронтенда HA и пользуется
  его соединением: никаких долгоживущих токенов, прокси и отдельных серверов. Ни адресов, ни токенов
  в конфиге карточки нет.
- **Раскладка хранится в самом дашборде.** Карточки, их размеры, дома и настройки слайдшоу записываются
  в конфиг этой карточки. Поэтому все планшеты и телефоны, открывающие дашборд, показывают одно и то же,
  а изменение на одном устройстве сразу появляется на остальных.
- **Менять раскладку может администратор HA** (запись в конфиг дашборда — его право).
  Остальные пользователи рамкой пользуются, но кнопки «Настроить» у них нет.
- **Фото — из медиатеки HA**, папка `/media/photoframe`. Загружать можно прямо с рамки
  («Настройки → Фото») или через «Медиа» в HA.
- **Стартовый экран — настройка устройства**, а не дашборда: на кухонном планшете — «Квартира · Кухня»,
  на даче — «Дача · Камеры».

## Установка

1. HACS → три точки → **Пользовательские репозитории** → `https://github.com/mZer0ne/lovelace-photoframe`,
   категория **Dashboard**.

   [![Открыть в HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=mZer0ne&repository=lovelace-photoframe&category=plugin)
2. Найдите **Photo Frame** в HACS и установите. Ресурс `/hacsfiles/lovelace-photoframe/dist/photoframe-card.js`
   HACS добавит сам (если нет — «Настройки → Дашборды → Ресурсы», тип *JavaScript-модуль*).
3. Создайте папку для фото: `/media/photoframe` (через Samba, File editor или терминал).
4. Обновите страницу и откройте любой дашборд администратором: Photo Frame предложит
   **создать дашборд «Фоторамка»** в боковом меню — одной кнопкой. Хотите вручную?
   Создайте дашборд → вид типа **Панель (одна карточка)** → добавьте карточку **Photo Frame**. Или в YAML:

```yaml
views:
  - title: Фоторамка
    type: panel
    cards:
      - type: custom:photoframe-card
        media_folder: photoframe
```

5. Откройте дашборд на планшете, смахните вверх, нажмите ✏️ и соберите свои карточки.

## Настройка

Всё настраивается на самой рамке, YAML трогать не нужно. Для справки — что хранится в конфиге карточки:

| Параметр | Что это | По умолчанию |
|---|---|---|
| `media_folder` | папка с фото в медиатеке HA | `photoframe` |
| `kiosk` | прятать шапку и меню HA (на устройстве можно переопределить) | `false` |
| `settings.slideIntervalMs` | смена фото, мс | `10000` |
| `settings.idleSec` | через сколько секунд без касаний вернуться к фото (0 — не возвращаться) | `45` |
| `layouts` | раскладки карточек по домам (заполняется редактором) | пример для первого запуска |
| `homes` | список домов (заполняется в «Настройки → Дома») | один дом |

## Киоск на планшете

- Откройте дашборд в приложении Home Assistant или в браузере в полноэкранном режиме.
- Чтобы экран не гас, рамка сама держит Wake Lock (нужен HTTPS). Если в настройках вашего приложения HA
  есть пункт «Не выключать экран», включите его тоже.
- **Встроенный режим киоска** прячет шапку и боковое меню HA, пока рамка на экране, и возвращает их,
  когда уходите с дашборда. Включается на устройстве («Настройки → Режим киоска на этом устройстве»),
  для всех — `kiosk: true` в конфиге карточки, или параметром `?kiosk` в адресе (`?kiosk=0` — выключить).

## Карточка HACS и отдельное приложение

Один и тот же интерфейс работает двумя способами — оба без токенов и отдельных серверов. Всё хранится в HA.

| | Карточка HACS | Отдельное приложение (PWA / Android-рамка) |
|---|---|---|
| Где работает | дашборд в HA или приложении HA | браузер, «на экран Домой», старая Android-рамка (APK-оболочка) |
| Доступ к HA | от вошедшего пользователя | вход через страницу входа HA, как у самого фронтенда HA |
| Дома и экраны | в конфиге карточки на дашборде | в той же карточке на дашборде «Фоторамка» |
| Фото | медиатека HA (`/media/photoframe`) | та же медиатека |

Приложение раздаёт сам HA: `./deploy.sh pwa` кладёт его в `<config>/www/photoframe`, и оно открывается по
`http://<HA>:8123/local/photoframe/index.html`. Открытое с того же домена (или внутри HA как дашборд
«Веб-страница») оно подхватывает ваш вход в HA, иначе — «Настройки → Home Assistant → Войти через Home Assistant».
Правка в карточке или на любой рамке сразу видна везде.

## Разработка

```bash
npm install
npm run dev            # PWA на http://localhost:5173 (вход в ваш HA — из её настроек)
npm run build:card     # dist/photoframe-card.js — файл для HACS
npm run apk:install    # APK-оболочка для старых рамок, ставится по adb
```

Стенд карточки с имитацией дашборда: `card-harness.html?ha=http://<HA>:8123` (данные — с вашего HA, только
чтение); `?hadom` ещё и повторяет DOM фронтенда HA — для проверки режима киоска.

**Деплой в свой HA** — `cp deploy.env.example .deploy.env`, заполните, затем:
`./deploy.sh card` кладёт свежую сборку в ваш HA (туда же, куда HACS, — удобно до релиза),
`./deploy.sh pwa` обновляет отдельное приложение в `www/photoframe`.

**Релиз** — `scripts/release.sh 0.2.0`: ставит версию, пересобирает `dist/photoframe-card.js`, ставит тег,
пушит и создаёт GitHub Release; workflow прикладывает к нему собранную карточку. HACS показывает
последний релиз как доступную версию.
